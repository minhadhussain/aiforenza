## Changes in this pass

- Added a redacted, test-only Stripe listener command (`npm run dev:payments`).
- Checkout success URL includes the session ID for precise confirmation display.

  refresh, and explains that balances belong to the account owning the key.

  completed events are acknowledged without credit and await paid confirmation.
- Fixed the PostgreSQL test fixture to include required package/INR fields and
  exercise the latest deployed INR completion function, not an obsolete version.
- Updated payment negative tests to start from a valid INR payload.
- Updated public `/docs` and operator documentation.
