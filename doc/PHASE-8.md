# Phase 8 - Dashboard

This phase adds the dedicated customer dashboard views described in the MVP specification.

## Included

- dashboard overview with live wallet and transaction summary
- dedicated API key view
- dedicated Add Funds / top-up view
- dedicated usage records view
- dedicated transactions view
- dedicated models/pricing view

## Notes

- the dashboard remains intentionally minimal
- tables are focused on operational visibility rather than advanced analytics
- model pricing shown in the dashboard comes from database-configured customer prices

## Deferred To Later Phases

- advanced charts and analytics
- admin-only business reporting
- richer filtering, exports, and search
